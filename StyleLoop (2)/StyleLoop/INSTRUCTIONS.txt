HOW TO RUN STYLELOOP

1. Extract this ZIP file.
2. Copy the StyleLoop folder to:
   C:\xampp\htdocs\
3. Open XAMPP Control Panel.
4. Start Apache and MySQL.
5. In your browser, run this first:
   http://localhost/StyleLoop/loadClothingStore.php
   This creates the ClothingStore database, tables and sample data.
6. Open the website:
   http://localhost/StyleLoop/index.php
